What Makes ऊttaram Different

A privacy-focused AI answering engine that runs on your own hardware, combines web knowledge with local and cloud LLMs, and delivers cited answers — all while keeping your data private.

🧠

Memories

Automatically extracts personal facts, preferences, and project info from your conversations. The LLM uses these to personalize answers across sessions. A health-check routine keeps the memory store clean.

📁

Projects

Organize chats into named groups. Create, rename, and delete projects; move chats between them; start new chats directly inside a project.

📏

Context Controls

Separate context length sliders for chat/vision models and embedding models. See token usage in real time with visual warnings as you approach limits.

⚡

Speed Mode

Answers directly without template structure for faster responses. Switch between Speed, Balanced, and Quality modes mid-conversation.

🔍

Smart Search

Search the web, discussions, or academic papers. Powered by SearXNG with support for multiple search engines. Domain-specific search available.

📎

File Uploads

Upload PDFs, text files, and images. Ask questions about them with automatic chunking and embedding based on your embedding model's context length.

🖼️

Image Upload & VLM

Upload images; a Vision Language Model describes them before the main LLM responds, so the model can answer questions about visual content.

📊

Analytics & Knowledge Graph

Obsidian-style interactive knowledge graph with hierarchical clustering, LLM-generated topic labels, and chat embeddings for semantic search across your history.

🔧

Pipeline Tracking

Real-time phase display during research (searching, extracting, writing). Timeout + automatic retries with visible progress. No silent failures.

📱

Mobile-First

Fully responsive UI with mobile-optimized settings, scrollable tab bars, and properly positioned popovers. Installable as a PWA on iOS Safari.

🔐

Privacy First

All data stays on your hardware. No cloud dependencies. LLM throttling prevents resource exhaustion when sharing a local model server.

✏️

Post-Answer Actions

Summarize long answers with one click, or fork a thread to continue a sub-topic without losing the original conversation.

Installation

Docker (Recommended)

docker run -d \
  -p 7777:3000 \
  -v $(pwd)/data:/home/uttaram/data \
  --name uttaram \
  kspviswa/uttaram:latest

Open http://localhost:7777 and configure your AI provider + SearXNG URL in the setup screen.

Docker Compose

services:
  uttaram:
    image: kspviswa/uttaram
    ports:
      - '7777:3000'
    volumes:
      - ./data:/home/uttaram/data
    restart: unless-stopped

Build from Source

git clone https://github.com/kspviswa/Uttaram.git
cd Uttaram
npm install
npm run build
npm start

Configuration

On first launch you'll enter the setup wizard:

  1. 1
    Enter your name and location

    Used to personalize greetings and timezone-aware responses.

  2. 2
    Add AI providers

    API keys and endpoints for OpenAI, Anthropic, Ollama, Groq, and more. Mix and match models.

  3. 3
    Select chat and embedding models

    Choose your default models. Separate context length controls for each model family.

  4. 4
    Configure SearXNG (optional)

    Set up your SearXNG URL for private web search.

All settings persist in the database and can be changed later under Settings.

Recent Changes

Embedding & Search

  • Embedding context length slider — Separate control for embedding model context window (up to 8K). Long texts are automatically chunked with 10% overlap and averaged into a single embedding.
  • Re-embed with progress — Backfill or re-generate embeddings with a progress bar.
  • MCP server — Search and crawl capabilities exposed via /api/mcp for tool integration.
  • Search performance indicator — Visual indicator showing whether results came from live web search or cached knowledge.

Knowledge & Analytics

  • Knowledge graph — Obsidian-style interactive graph with hierarchical clustering and LLM-generated topic labels.
  • Chat embeddings & analytics — Semantic search across chat history with cluster visualization and embedding status tracking.
  • @ chat references — Link chats to related conversations using @ references.

Performance

  • Speed mode — Answers directly without template structure for faster responses.
  • Classifier LLM removed — Eliminated an extra LLM call per query.
  • LLM label caching — Cluster topic labels are cached to avoid redundant LLM calls.
  • Memory health check batch size — Reduced to 10 memories per batch for more reliable processing.
  • Text chunking for embeddings — Automatic chunking based on embedding model context length prevents errors with limited-context models.

Mobile & UX

  • Mobile responsive UI — Full responsive layout with mobile-optimized settings and scrollable tab bars.
  • Optimization popover positioning — Properly positioned on all screen sizes with mobile adjustments.
  • Dismissable modals — Bottom-sheet modals for mobile optimization pickers.
